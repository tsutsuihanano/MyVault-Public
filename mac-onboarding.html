Mac セットアップ最低限ガイド

Windows から Mac に乗り換えた人向け・仕事で困らない最小構成

⏱️ 所要時間：約30〜60分

1. なぜやる？（Before / After）

素の Mac だと

  • アプリ起動が Launchpad から手探り
  • ウィンドウを画面の半分にしたい時は手動ドラッグ
  • スクショ撮ってもファイルだけ、Slack 貼付が一手間
  • 1個前にコピーした内容は消える
  • ⌘+Tab で同じアプリの別ウィンドウが出ない
  • 日本語入力が「Caps Lock 風」のキーで切替
  • 紛失したら中身丸見え

このガイドの後

  • ⌘+Space → 「fig」で Figma 即起動
  • Control+Option+→ でウィンドウ右半分にスナップ
  • スクショは自動でクリップボードへ → 即貼付
  • Option+V でコピー履歴を呼び出せる
  • Option+Tab で全ウィンドウのサムネ一覧
  • 「英数」キー連打で英数⇔かなトグル（Windows 風）
  • FileVault で盗難・紛失時もデータ保護

STEP 1. Homebrew のインストール

やること

標準アプリ ターミナル.app（Spotlight検索で「ターミナル」または Launchpad → その他 → ターミナル）を起動して、以下を順に実行。

# 1. Homebrew インストール（公式コマンド） /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" # パスワード求められたら Mac のログインパスワードを入力 # 終わったら表示される「Next steps:」のコマンド2行をコピペして実行（PATHを通す） # 2. 動作確認 brew --version

Homebrew 4.x.x と表示されればOK。

補足

Intel Mac の場合、Homebrew のパスが /usr/local/bin/brew になる。Apple Silicon（M1/M2/M3/M4）は /opt/homebrew/bin/brew。

STEP 2. アプリ一括インストール

やること

ターミナルで以下を1コマンドで実行。これだけで主要アプリが入る。

brew install --cask raycast rectangle alt-tab shottr karabiner-elements lulu

ダウンロード&インストールが順次走る。各アプリ /Applications/ 配下に配置される。所要 5 分前後。

STEP 3. 各アプリの初期設定

3-1. Raycast（最重要）
  1. Launchpad から Raycast 起動
  2. ウィザードに従って進める
  3. ⌘+Space を Raycast のホットキーに設定（macOS 標準の Spotlight は無効化される）
  4. クリップボード履歴: Raycast 起動 → 「Clipboard History」検索 → Record Hotkey で Option+V を設定
3-2. Rectangle
  1. Launchpad から Rectangle 起動
  2. 「アクセシビリティ」の権限要求 → システム設定で許可
  3. デフォルトのショートカットでOK（左半分 Control+Option+← / 右半分 Control+Option+→ / 最大化 Control+Option+Return）
3-3. AltTab
  1. Launchpad から AltTab 起動
  2. 「アクセシビリティ」「画面収録」の権限要求 → 許可
  3. デフォルトの Option+Tab でOK
3-4. Shottr
  1. Launchpad から Shottr 起動
  2. 「画面収録」の権限要求 → 許可
  3. 環境設定 → ショートカット → 範囲スクショを Option+S に設定
  4. 環境設定 → 一般 → 「Copy and Save」を ON（クリップボード＋ファイル保存）
3-5. Karabiner-Elements（英数/かなトグル）
  1. Launchpad から Karabiner-Elements 起動
  2. 各種権限ダイアログ → システム設定で順次許可
    • Background Services（ログイン項目）
    • Accessibility（アクセシビリティ）
    • Capture Input Events（入力監視）
    • Driver Extension（ドライバ機能拡張）
  3. ターミナルで以下を実行して設定ファイルを配置（「英数キー / かなキー単独押しで英数⇔かなをトグル」ルール）:
mkdir -p ~/.config/karabiner cat > ~/.config/karabiner/karabiner.json << 'EOF' { "global": { "check_for_updates_on_startup": true, "show_in_menu_bar": true, "show_profile_name_in_menu_bar": false }, "profiles": [ { "complex_modifications": { "rules": [ { "description": "英数キーまたはかなキー単独押しで英数⇔かなをトグル", "manipulators": [ { "type": "basic", "from": { "key_code": "japanese_eisuu" }, "to": [ { "key_code": "japanese_kana" }, { "set_variable": { "name": "ime_state", "value": 1 } } ], "conditions": [ { "type": "variable_unless", "name": "ime_state", "value": 1 } ] }, { "type": "basic", "from": { "key_code": "japanese_eisuu" }, "to": [ { "key_code": "japanese_eisuu" }, { "set_variable": { "name": "ime_state", "value": 0 } } ], "conditions": [ { "type": "variable_if", "name": "ime_state", "value": 1 } ] }, { "type": "basic", "from": { "key_code": "japanese_kana" }, "to": [ { "key_code": "japanese_kana" }, { "set_variable": { "name": "ime_state", "value": 1 } } ], "conditions": [ { "type": "variable_unless", "name": "ime_state", "value": 1 } ] }, { "type": "basic", "from": { "key_code": "japanese_kana" }, "to": [ { "key_code": "japanese_eisuu" }, { "set_variable": { "name": "ime_state", "value": 0 } } ], "conditions": [ { "type": "variable_if", "name": "ime_state", "value": 1 } ] } ] } ] }, "name": "Default profile", "selected": true, "virtual_hid_keyboard": { "country_code": 8, "keyboard_type_v2": "jis" } } ] } EOF

Karabiner-Elements を一度終了 → 起動し直すと反映。

Karabiner の注意

Karabiner はキー入力を全部処理する性質上、稀に Ctrl+Shift+◯ などの組み合わせを取りこぼすことがある。問題が出たら Karabiner 設定で該当ルールを OFF にすれば素の動作（英数キーで英数固定・かなキーでかな固定）に戻る。

3-6. LuLu
  1. Launchpad から LuLu 起動
  2. ウィザードに従って Install
  3. システム拡張の許可ダイアログ → システム設定 → ログイン項目と機能拡張 → 機能拡張セクション内の「ネットワーク機能拡張」→ LuLu のトグル ON → 認証
  4. 「"LuLu" Would Like to Filter Network Content」→ Allow
  5. 以降、知らないアプリが通信しようとすると通知が出る → 信頼できるなら Allow、不審なら Block

STEP 4. macOS のシステム設定

4-1. Dock 自動非表示 + Finder 拡張子表示（ターミナルで一括）
# Dock を自動非表示 defaults write com.apple.dock autohide -bool true && killall Dock # Finder で拡張子を常に表示 defaults write NSGlobalDomain AppleShowAllExtensions -bool true && killall Finder
4-2. FileVault（⭐最重要・ディスク暗号化）
  1. システム設定 → プライバシーとセキュリティ → 下の方の FileVault → 「オンにする」
  2. 復旧方法 → 「iCloud アカウントを使用」（推奨・パスワード忘れた時に Apple ID で復旧可）
  3. パスワード入力 → 暗号化が開始（バックグラウンドで進行・放置で OK）

M1/M2/M3/M4 Mac はハードウェア暗号化なので動作速度の体感差ゼロ。仕事用なら絶対 ON 推奨。

4-3. ファイアウォール
  1. システム設定 → ネットワーク → ファイアウォール → トグル ON
4-4. CapsLock → Control（任意）
  1. システム設定 → キーボード → 「キーボードショートカット…」 → 修飾キー
  2. 「Caps Lock キー」のプルダウンを Control に変更 → OK

普段使わない CapsLock を Control として活用できる。元に戻したくなったら同じ画面で「Caps Lock」に戻すだけ。

  • ⌘+Space で Raycast が起動する
  • Raycast で「fin」と打って Finder が起動できる
  • Option+V でクリップボード履歴が出る
  • Control+Option+→ で今のウィンドウが右半分にスナップ

  • Option+S で範囲スクショが撮れる（クリップボードに自動で入る）
  • 何かの入力欄で 「英数」キー or「かな」キーを連打すると英数⇔かながトグルする

  • システム設定 → FileVault が「オン」になっている
  • システム設定 → ファイアウォールが「オン」になっている
  • Dock が自動で隠れる・ファイル名の拡張子が見える

6. 困った時

brew で「command not found: brew」
PATH が通っていない。Apple Silicon は echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile → source ~/.zprofile。Intel Mac は /usr/local/bin/brew。
アプリのショートカットが効かない
ほぼ「権限が許可されていない」のが原因。システム設定 → プライバシーとセキュリティ → アクセシビリティ / 入力監視 / 画面収録 の各タブで該当アプリのトグルが ON か確認。
スクショ撮ってもクリップボードに入らない
Shottr の環境設定 → 一般 → 「Copy and Save」が ON か確認。OFF だとファイル保存のみ。
英数/かなトグルが動かない
Karabiner-Elements が起動しているか確認（メニューバーにアイコン）。設定ファイル ~/.config/karabiner/karabiner.json の内容が正しいか確認。Karabiner を再起動すると反映。
Karabiner で Ctrl+Shift+◯ が時々効かない
Karabiner のキー処理タイミングの問題。気になるなら Karabiner 設定 → Complex Modifications で該当ルールを Disable。素の挙動（英数キー/かなキーがそれぞれモード固定）に戻る。
LuLu のシステム拡張が許可できない
システム設定 → プライバシーとセキュリティ の一番下に「LuLu のシステムソフトウェアの読み込みがブロックされました」のような表示があれば「許可」を押す。または ログイン項目と機能拡張 → 機能拡張 → ネットワーク機能拡張 のリストから LuLu を ON。
FileVault 暗号化が終わらない
バックグラウンドで進行するので普通に使ってOK。電源につないでおくと早く完了する。途中で電源切れても再開される。
困ったら最終手段
スクショ撮ってチャットで聞く。設定で迷ったら、ほぼ全部「システム設定 → プライバシーとセキュリティ」で権限 ON/OFF が確認できる。Raycast (⌘+Space) でアプリ名を打てば大抵起動できる。
ここまで完了すれば、Windows でやってた便利な操作のほとんどが Mac でもできる状態。
