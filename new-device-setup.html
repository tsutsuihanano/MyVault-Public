STEP 1. ベースツールのインストール

Mac の場合

標準アプリ「ターミナル.app」を起動して、以下を順に実行する。

🍎 macOS
# 1. Homebrew インストール /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" # 2. PATH を通す（Apple Silicon の場合） echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile source ~/.zprofile # 3. 必要なツールを一括インストール brew install git gh node@20 pyenv # 4. 動作確認 brew --version git --version gh --version node --version
Windows の場合

PowerShell（管理者）で実行。Wingetが入っていなければ Microsoft公式からインストール。

🪟 Windows
# Winget で一括インストール winget install --id Git.Git -e winget install --id GitHub.cli -e winget install --id OpenJS.NodeJS.LTS -e # 動作確認（新しいPowerShellを開き直して） git --version gh --version node --version

STEP 2. GitHub 認証（gh auth login）

やること

GitHub CLI 経由で認証するのが一番ラク。トークン手動発行は不要。

gh auth login

対話プロンプトの選択：

  1. GitHub.com を選択
  2. HTTPS を選択
  3. Yes（Authenticate Git with GitHub credentials）
  4. Login with a web browser を選択
  5. 表示される8桁コードをコピー → ブラウザで貼り付け → 承認
# 確認（✓ Logged in to github.com as ... が出れば成功） gh auth status # Git のユーザー設定（メイン端末と同じ値で） git config --global user.name "MyVault User" git config --global user.email "your-email@example.com"
この後

一度認証すれば、その端末では git push / pull / clone がすべて自動で認証される。PAT（Personal Access Token）の手動発行は不要。

STEP 3. MyVault を GitHub から clone

やること
🍎 macOS
mkdir -p ~/Documents cd ~/Documents gh repo clone <your-github-username>/MyVault cd MyVault git status # クリーンならOK
🪟 Windows（PowerShell）
cd $env:USERPROFILE\Documents gh repo clone <your-github-username>/MyVault cd MyVault git status
注意点

.secrets/ は cloneに含まれない（gitignoreされている）。次のSTEPで手動コピーが必要。

STEP 4. .secrets を手動でコピー

やること

認証情報（Google Sheets / Gmail / Google Ads / Chatwork API）はGit対象外。OneDrive経由で運ぶのが安全。

  1. メイン端末の .secrets をOneDriveにアップロード（既に同期済みならスキップ）
  2. 新端末でOneDriveをサインイン → 同期完了を待つ
  3. .secrets フォルダごと ~/Documents/MyVault/ 配下にコピー
🍎 macOS
# OneDriveのパスは環境による（CloudStorage配下） cp -r ~/Library/CloudStorage/OneDrive-*/.secrets ~/Documents/MyVault/ # 認証ファイルのパーミッションを絞る chmod 600 ~/Documents/MyVault/.secrets/*.json chmod 600 ~/Documents/MyVault/.secrets/*.txt
🪟 Windows
Copy-Item -Recurse $env:OneDrive\.secrets $env:USERPROFILE\Documents\MyVault\
超重要

絶対に .secrets/ をGit add しないこと。 .gitignore に登録済みだが、OS差異で外れることがあるので push前に git status で確認すること。

STEP 5. Obsidian インストール → Vaultとして開く

インストール
🍎 macOS
brew install --cask obsidian
🪟 Windows
winget install --id Obsidian.Obsidian -e
起動後の操作
  1. 「フォルダを Vault として開く」を選択
    （Open folder as vault / フォルダーをボルトとして開く）
  2. ~/Documents/MyVault を選択
  3. 「コミュニティプラグインを有効化」→「全て有効化」
    .obsidian/community-plugins.json に記録された全プラグインが自動で再ダウンロードされる（Obsidian Git含む）
この後

Obsidian の設定（テーマ・ホットキー・スニペット）は .obsidian/ 配下にあるため、git pull した時点で自動で揃う。

STEP 6. Cursor インストール → Settings Sync

インストール
🍎 macOS
brew install --cask cursor
🪟 Windows
winget install --id Anysphere.Cursor -e
起動後の操作
  1. サインイン（GitHub or Google）— メイン端末と同じアカウントを使うとProプランが共有される
  2. 設定 → Settings Sync → Turn On → GitHubアカウントで認証
  3. テーマ・拡張機能・キーバインドが自動同期される
  4. File → Open Folder → ~/Documents/MyVault
注意点

メイン端末でSettings Sync未設定なら、先にメイン端末でオンにして設定をアップロード → その後新端末でオンにする順序で。

STEP 7. Claude Code 設定の同期

考え方

グローバルCLAUDE.md・メモリ・skillsを 専用リポジトリ（claude-config） で管理して、両端末で symlink で参照する。

メイン端末側で1回だけ実行

既にやっていればスキップ。

# 1. プライベートリポジトリ作成 gh repo create claude-config --private --description "Claude Code設定の同期" # 2. 必要ファイルをコピー mkdir ~/claude-config cd ~/claude-config cp ~/.claude/CLAUDE.md . cp ~/.claude/settings.json . cp -r ~/.claude/skills . mkdir memory cp ~/.claude/projects/<vault-project-id>/memory/*.md memory/ # 3. .gitignore で不要物を除外 cat > .gitignore <<EOF *.local session_* *.bak EOF # 4. push git init git add . git commit -m "initial: Claude Code設定の同期" git branch -M main git remote add origin https://github.com/<your-github-username>/claude-config.git git push -u origin main
新端末側で実行
# 1. clone cd ~ gh repo clone <your-github-username>/claude-config cd claude-config # 2. 既存の ~/.claude/ ファイルをバックアップ → symlink を張る mv ~/.claude/CLAUDE.md ~/.claude/CLAUDE.md.bak 2>/dev/null ln -s ~/claude-config/CLAUDE.md ~/.claude/CLAUDE.md mv ~/.claude/settings.json ~/.claude/settings.json.bak 2>/dev/null ln -s ~/claude-config/settings.json ~/.claude/settings.json mv ~/.claude/skills ~/.claude/skills.bak 2>/dev/null ln -s ~/claude-config/skills ~/.claude/skills # 3. memory フォルダの symlink # Macのプロジェクトディレクトリは ~/.claude/projects/-Users--Documents-MyVault/ PROJECT_ID="-Users-$(whoami)-Documents-MyVault" mkdir -p ~/.claude/projects/$PROJECT_ID ln -s ~/claude-config/memory ~/.claude/projects/$PROJECT_ID/memory
注意点

CLAUDE.md の Mac/Win 差異：パス（C:\Users\... vs /Users/...）やシェル（PowerShell vs zsh）の記述差を吸収するため、CLAUDE.mdに OS判定ブロックを追加するか、必要箇所だけMac用に書き換える。

メモリは両端末で共有・追記される。同時に2端末で開いて編集すると競合するので、片方を閉じてから作業を切り替える運用を推奨。

3. 完了チェック

  • brew / git / gh / node コマンドが新端末で動く
  • gh auth status で認証済みと表示される
  • ~/Documents/MyVault が cloneされ、git status がクリーン
  • ~/Documents/MyVault/.secrets/ に認証ファイル群がある
  • Obsidian で MyVault が開け、コミュニティプラグインが有効
  • Cursor で Settings Sync が有効、MyVault フォルダを開いている
  • ~/.claude/CLAUDE.md が ~/claude-config/CLAUDE.md へのsymlink
  • ~/.claude/projects/.../memory に過去のメモリファイルが見える

4. 困った時（トラブルシューティング）

brew install で「command not found: brew」
Homebrew のPATHが通っていない。echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile → source ~/.zprofile を実行。Intel Macは /usr/local/bin/brew。
gh auth login で「could not prompt」エラー
対話モードが効いていない。新しいターミナルウィンドウで実行する。SSH越しの場合は --web オプションを付ける：gh auth login --web
git clone で「Permission denied」または「Authentication failed」
STEP 2 の gh auth login が完了していない可能性。gh auth status で確認 → 失敗していたら再度 gh auth login。
.secrets が同期されない
.gitignore に .secrets/ が登録されているため、git経由では絶対に来ない。OneDrive・USB・AirDrop 等で手動コピーが必須。
Obsidian でプラグインが有効にならない
設定 → コミュニティプラグイン → 「制限モード」をオフ → プラグイン一覧で個別に「有効化」ボタンを押す。.obsidian/community-plugins.json に記録があれば、必要なプラグインは自動でインストール提案される。
Claude Code を起動してもメモリが反映されない
symlink先のパスが間違っている可能性。ls -la ~/.claude/projects/ で実際のプロジェクトディレクトリ名を確認 → そこに claude-config/memory のsymlinkを張り直す。プロジェクトID は端末・OS・ユーザー名で変わる。
同期で衝突（conflict）
2端末で同じファイルを同時に編集した場合に発生。Obsidian Git で「Pull」→ 衝突マーカー（<<<）を手動解決 → コミット。同時に2端末で開かない運用が予防策。
