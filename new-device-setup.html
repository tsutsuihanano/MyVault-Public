⏱️ 所要時間：約60分（DL時間込み）

STEP 1. ベースツールのインストール

Macbookでやる

標準アプリ ターミナル.app（Spotlight検索で「ターミナル」）を起動して、以下を順に実行。

💻 Macbook
# 1. Homebrew インストール /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" # 2. PATH を通す（Apple Silicon の場合） echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile source ~/.zprofile # 3. 必要ツール一括インストール brew install git gh node@20 # 4. 動作確認 brew --version git --version gh --version node --version
注意

Intel Mac の場合、Homebrew のパスが /usr/local/bin/brew になる。エラーが出たらこちらでPATHを通す。

STEP 2. GitHub 認証

Macbookでやる
gh auth login

対話プロンプトの選択：

  1. GitHub.com を選択
  2. HTTPS を選択
  3. Yes（Authenticate Git with GitHub credentials）
  4. Login with a web browser を選択
  5. 表示される8桁コードをコピー → ブラウザで貼り付け → 承認
# 確認: ✓ Logged in to github.com as tsutsuihanano が出れば成功 gh auth status # Git のユーザー設定（デスクトップと揃える） git config --global user.name "MyVault User" git config --global user.email "tsutsui@shibuya-ad.com"

STEP 3. MyVault を clone

Macbookでやる
💻 Macbook
mkdir -p ~/Documents cd ~/Documents gh repo clone tsutsuihanano/MyVault cd MyVault git status # クリーンならOK ls -la # .obsidian/ .claude/ 00_Inbox/ などが見えれば成功
注意

.secrets/ は cloneに含まれない（gitignoreされている）→ 次のSTEP 4 でCWから取得する。

STEP 4. secrets.zip を CW から取得して展開

手順

📥 CWの該当メッセージを開く（secrets.zip）

  1. 上のリンクを開く（ブラウザでChatworkの該当メッセージに直接ジャンプ。業務アカウントでログイン状態が必要）
  2. 添付の secrets_YYYYMMDD_HHMMSS.zip をクリック → ダウンロード（標準で ~/Downloads/）
  3. ターミナルで以下を実行：
💻 Macbook
# MyVault配下の .secrets として展開 cd ~/Documents/MyVault mkdir -p .secrets unzip -o ~/Downloads/secrets_*.zip -d .secrets # パーミッションを絞る（漏洩対策） chmod 700 .secrets chmod 600 .secrets/*.json chmod 600 .secrets/*.txt # 中身確認 ls -la .secrets/
作業後 必ずやること
  1. 展開が成功したら、CWマイチャットの secrets.zip メッセージを削除（添付ファイル含めて完全削除）
  2. Macbookの ~/Downloads/secrets_*.zip も削除
  3. 絶対に .secrets/ をGit add しないこと。push前に git status で確認

STEP 5. memory.zip を CW から取得して展開

手順

📥 CWの該当メッセージを開く（memory.zip）

  1. 上のリンクを開く
  2. 添付の memory_YYYYMMDD_HHMMSS.zip をクリック → ダウンロード
  3. ターミナルで以下を実行：
💻 Macbook
# Claude Codeのプロジェクトディレクトリに memory フォルダを作成 # Macのプロジェクトディレクトリ命名: -Users-<user>-Documents-MyVault PROJECT_ID="-Users-$(whoami)-Documents-MyVault" TARGET="$HOME/.claude/projects/$PROJECT_ID/memory" mkdir -p "$TARGET" unzip -o ~/Downloads/memory_*.zip -d "$TARGET" # 中身確認（30+件のmdファイルが見えれば成功） ls -la "$TARGET"
補足

このメモリには「はな乃さんの好み」「業務プロジェクトの背景」「過去の指摘事項」など、Claude Codeとの会話を蓄積した知見が入っている。これがあるとMacでもClaudeが「同じ感覚」で受け答えできる。

作業後 必ずやること
  1. 展開成功後、CWマイチャットの memory.zip メッセージを削除
  2. ~/Downloads/memory_*.zip も削除

STEP 6. Obsidian インストール → Vaultとして開く

インストール
💻 Macbook
brew install --cask obsidian
初回起動時の警告

初回起動時に「開発元が確認できないため開けません」というGatekeeper警告が出ることがある。その場合：
Finder で アプリケーション → Obsidian を右クリック →「開く」を選ぶ → 警告ダイアログで「開く」をクリック。次回からは普通に起動できる。

起動後の操作
  1. 「フォルダを Vault として開く」を選択
    （Open folder as vault）
  2. ~/Documents/MyVault を選択
  3. 「コミュニティプラグインを有効化」→制限モードを解除→「有効化」を全プラグインに対して実行
    .obsidian/community-plugins.json に記録された全プラグインが自動で再ダウンロードされる（Obsidian Git含む）
  4. 右下にGitアイコン（同期マーク）が出れば、自動同期が稼働している証拠
この後

Obsidian の設定（テーマ・ホットキー・スニペット）は .obsidian/ 配下にあり、git pull で自動取得済み。追加設定は不要。

STEP 7. Cursor インストール（ターミナル用途・最小設定）

前提

はな乃さんの運用は 「Cursorのターミナルで Claude Code を起動」 がメイン。エディタ・拡張機能・テーマは使わない想定なので、Settings Sync などの追加設定は不要。デフォルト状態でインストールするだけ。

インストール
💻 Macbook
brew install --cask cursor
初回起動時の警告

同様にGatekeeper警告が出る場合あり：アプリケーション → Cursor を右クリック →「開く」。

起動後の操作
  1. 初回起動でサインイン画面が出る → GitHub or Googleでログイン（デスクトップと同じアカウントが望ましい）
  2. File → Open Folder → ~/Documents/MyVault を選択
  3. ターミナルを開く: メニューの「Terminal」→「New Terminal」 または ショートカット ⌃ + `
  4. ターミナルで claude と打って Claude Code を起動
この後

これでデスクトップと同じく 「Cursorを開いて → ターミナル → claude」 の流れで作業できる状態。
拡張機能やテーマの同期は不要なので、Settings Sync の設定は触らない。

補足

Claude Code 本体（claude コマンド）は次の STEP 8 でインストールするので、ここで claude を打って動かなくても問題ない。

STEP 8. Claude Code インストール → CLAUDE.md / settings.json 配置

考え方

デスクトップの ~/.claude/CLAUDE.md はWindowsパス・PowerShellコマンド前提で書かれている。そのままMacに持ち込むと矛盾するので、Mac用に作る。プロジェクトCLAUDE.md（MyVault/CLAUDE.md）はMyVault同期で既に揃っているのでそのまま使える。

面倒な作業は Claude Code 自身に依頼 する方が安全（パスやシェル差異の手書きミスを防げる）。これは西村さん推奨の方式。

Claude Code インストール
💻 Macbook
# Cursor のターミナル（⌃+`）で実行 npm install -g @anthropic-ai/claude-code # MyVaultフォルダで Claude Code 起動 cd ~/Documents/MyVault claude

📌 初回起動時のログイン: claude を実行すると、ブラウザが自動で開いて Anthropic アカウントのログイン画面に飛ぶ。Claude Max を契約しているアカウントでログイン → 承認 → ターミナルに戻る → プランは「Max」を選択。

起動後にClaudeに依頼するプロンプト（コピペ）

Claude Code が起動したら、下記をそのままコピペして送る：

~/.claude/CLAUDE.md（グローバル設定）と ~/.claude/settings.json を Mac用に配置してほしい。 【1】~/.claude/CLAUDE.md の要件: - 日本語で応答する - 結論から入る・推測禁止・不明点は質問する - 端末呼称: デスクトップ=Windowsメイン機(hostname:HANANO) / Macbook=この端末 - パス: MyVaultは ~/Documents/MyVault に配置 - シェル: zsh / bash（PowerShellではない、Bashツール優先） - 一時ファイルは ~/Downloads に出す（MyVault配下に作らない） - 認証情報は ~/Documents/MyVault/.secrets/ に格納（git対象外） - メモリは ~/.claude/projects/-Users-$(whoami)-Documents-MyVault/memory/ にある - セッション開始時にメモリ読込 デスクトップ側のCLAUDE.mdの構成（Plan→Execute / 並列エージェント運用 / 検証 / コーディング原則 / 制約 / Anti-patterns）を踏襲しつつ、Mac環境にfitするように作成して。 【2】~/.claude/settings.json は以下の内容で作成: { "permissions": { "allow": ["Bash", "Read", "Edit", "Write", "Glob", "Grep"] }, "theme": "dark-daltonized" } → これによりBash/Read/Edit/Write/Glob/Grep は毎回確認なしで自動実行になり、デスクトップと同じ快適さで使える。
確認

Claude が ~/.claude/CLAUDE.md を生成し終わったら、何か業務に関する質問をしてみる。
→ メモリの内容（過去の好み・プロジェクト背景）を踏まえた応答が返ってくればセットアップ完了。
例: 「数字合わせのワークフロー教えて」「タスク管理シートのURL覚えてる？」

プロジェクトCLAUDE.mdは触らない

~/Documents/MyVault/CLAUDE.md（プロジェクトCLAUDE.md）はWindowsパスやPowerShellコマンドが含まれているが、これはデスクトップでも編集する共有ファイル。Mac固有の差異は将来 OS判定ブロックで吸収する想定。今は触らずそのまま使う。

運用ルール（西村さん推奨）

Claude が「○○を実行してよいですか？」と聞いてきたら、基本的に 「はい」 と答える。
「やっていいよ」「進めて」「OK」など、自然な返答でOK。慎重なら /permissions で個別ツールを許可リストに追加する運用に切り替えると毎回聞かれなくなる。

STEP 9. AXAD DB の MCP 接続設定（任意）

対象

Macbookから AXAD DB（PostgreSQL/Neon）にクエリを投げたい場合だけ実行する。
数字合わせ・案件分析・campaigns テーブル参照などで mcp__axad__query を使う運用ならこのSTEPが必要。

手順

Claude Code（前STEPで起動済み）に下記プロンプトをそのまま貼り付ける。MCP設定ファイル ~/.mcp.json が自動生成される（西村さん提供方式）。

以下の手順を実行して、AXADデータベースへのMCP接続を設定してください。 1. ~/.mcp.json を読み込む（なければ新規作成） 2. mcpServers に以下を追加（既存の設定は残す）: { "axad": { "command": "npx", "args": [ "-y", "@modelcontextprotocol/server-postgres", "postgresql://tsutsui:38a2683c2dc1d1b1fbf1212f6312fb37babcd0775e048cd2@ep-frosty-mountain-a1l9h522-pooler.ap-southeast-1.aws.neon.tech/neondb?sslmode=require" ] } } 3. 設定完了後「SELECT count(*) FROM campaigns」を実行して接続確認
確認

Claude が ~/.mcp.json 作成 → SELECT count(*) FROM campaigns 実行 → 件数が返ってくれば成功。
※ MCP接続を有効化するには Claude Code の再起動が必要な場合あり。/quit で抜けてもう一度 claude。

注意

この接続文字列は 個人用（はな乃さん専用）。他人と共有しない。
権限: campaigns テーブルのみ参照可（SELECTのみ）。

5. 困った時（トラブルシューティング）

brew で「command not found: brew」
PATHが通っていない。echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile → source ~/.zprofile。Intel Macは /usr/local/bin/brew。
gh auth login で「could not prompt」
対話モードが効いていない。新しいターミナルウィンドウで実行。SSH越しの場合は gh auth login --web。
git clone で「Permission denied」
STEP 2 の gh auth login が完了していない。gh auth status で確認 → 失敗していたら再度ログイン。
unzip コマンドが見つからない
macOS には標準で入っているはず。出ない場合は brew install unzip。あるいはFinderで該当zipをダブルクリック → 展開フォルダを所定パスにドラッグ&ドロップでも可。
CWマイチャットにzipファイルが見当たらない
デスクトップ側でアップロードが完了していない可能性。デスクトップ側に戻って、.secrets と memory をzip化 → CW APIまたはCWアプリでマイチャット（ルームID 375447268）にアップロード。ファイル名は secrets_YYYYMMDD_HHMMSS.zip / memory_YYYYMMDD_HHMMSS.zip 形式。
Obsidian でプラグインが有効にならない
設定 → コミュニティプラグイン → 「制限モード」をオフ → プラグイン一覧で個別「有効化」。.obsidian/community-plugins.json に記録があれば必要なものは自動でインストール提案される。
Claude Code を起動してもメモリが認識されない
PROJECT_IDのパスが間違っている可能性。ls ~/.claude/projects/ で実際のディレクトリ名を確認 → そこに memory フォルダを置き直す。Mac版の命名は -Users-<ユーザー名>-Documents-MyVault。
Obsidian Gitで競合（conflict）
2端末で同じファイルを同時に編集した場合に発生。Obsidian Git の「Pull」→ 衝突マーカーを手動解決 → コミット。同時に2端末で開かない運用が予防策。
ここまで完了すればMacbookはデスクトップとほぼ同じ環境。
以降はMyVault変更は5分ごとに両端末で自動同期、Claudeのメモリも引き継がれた状態で作業を継続できる。
