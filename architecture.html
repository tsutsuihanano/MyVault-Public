🔧 各ツールの役割

Obsidian

  • ノートの作成・編集
  • 双方向リンクで知識を接続
  • グラフビューで全体俯瞰
  • Git プラグインで自動同期

Cursor

  • AI による情報整理・構造化
  • タスク管理の自動化
  • スクリプト実行・API連携
  • ドキュメント・資料生成

GitHub

  • バージョン管理（履歴保全）
  • 複数端末間の同期ハブ
  • クラウドバックアップ

🔄 データの流れ

sequenceDiagram participant U as 👤 ユーザー participant O as Obsidian participant G as GitHub participant O2 as Obsidian（別端末） U->>O: ノートを編集 Note over O: 5分ごとに自動バックアップ O->>G: git commit + push（自動） Note over G: 変更を保存 O2->>G: git pull（自動 / 起動時） G->>O2: 最新のノートを取得 U->>O2: 別端末でも最新状態で作業
